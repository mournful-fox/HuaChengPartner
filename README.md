# 🦋 Хуа Чен на рабочем столе

Некоммерческий фанатский десктоп-компаньон для Windows: чиби-Хуа Чен живёт над панелью задач и помогает как ИИ-агент.
Его дело — хозяйство: напоминания, дела, загрузки, вкладки, память, дневник и вечера кино.

Это самостоятельная программа: её достаточно одной. Если на компьютере есть и другие персонажи
(Вэй Усянь, Лань Чжань — отдельные программы), они находят друг друга сами, и появляются совместные действия.

## Запуск
1. Положи `HuaCheng.exe` в постоянную папку и запусти. Права администратора не нужны.
   SmartScreen может предупредить о неподписанном файле: «Подробнее» → «Выполнить в любом случае».
2. Правый клик по персонажу → «Настройки…» → выбери модель ИИ (Gemini бесплатно, Groq, xAI Grok, OpenAI или локально Ollama)
   и вставь ключ. Если на компьютере уже настроен Хуа Чен, ключи возьмутся у него.
3. Двойной клик или **Ctrl+Alt+Space** — чат. **Ctrl+Alt+V** — сказать голосом. **Ctrl+Alt+S** — посмотреть на экран.
   **Ctrl+Alt+C** — текст из буфера. **Ctrl+Alt+H** — спрятать.

## Вместе с другими
- **С Вэй Усянем:** после 19:00 Хуа Чен зовёт его на вечер кино — вино, кости, топ-3 фильмов во вкладках, шутливые драки.
- **С Лань Чжанем:** тот приходит с 8:00 каждые 3 часа и зовёт учиться; на 11-й раз открывает учёбу в Firefox под будильник (а если есть Вэй Усянь — уводит его за руку и закрывает вкладки с фильмами).
- С любым из них: перебранки, «Позвать друга» в меню и словами.

Персонажи узнают друг о друге из файла `%APPDATA%\HuaChengPartner\friends.json`: каждый записывает туда себя
при запуске. Поэтому друга нужно хотя бы раз запустить. Удалила программу — он из списка пропадает сам.

## Данные
`%APPDATA%\HuaChengPartner\config.json` — настройки, ключи API (открытым текстом — не публикуй), память.
Расширение Chrome (меню → «Расширение для Chrome…») одно на всех персонажей.

## Сборка из исходников
```
pip install -r requirements.txt
python main.py
build.bat        → dist\HuaCheng.exe
```

## Устройство
| Файл | Что внутри |
|---|---|
| `characters.py` | характер, позы, реплики и набор умений этого персонажа |
| `main.py`, `hua.py` | окно персонажа, меню, настройки, анимация |
| `agent.py` | ИИ: провайдеры, инструменты |
| `ipc.py` | поиск друзей и связь с ними |
| `evening.py` | совместные сцены (ведёт Хуа Чен) и списки фильмов |
| `life.py`, `features.py`, `tools_pc.py`, `slides.py` | таймеры, память, погода, файлы, презентации |
| `chat.py`, `bridge.py`, `effects.py`, `config.py`, `phrases.py`, `eming.py` | чат, Chrome, эффекты, настройки |

Код у трёх программ общий по происхождению, но копии независимы: менять можно что угодно.
Не меняй только формат сообщений в `ipc.py` и имена поз, иначе персонажи перестанут понимать друг друга.
