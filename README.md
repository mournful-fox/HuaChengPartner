# 🦋 Хуа Чен на рабочем столе

Некоммерческий фанатский десктоп-компаньон для Windows. Чиби-Хуа Чен живёт над панелью задач, выпускает серебряных бабочек, спорит с Э-Мином и помогает как ИИ-агент: напоминает, разбирает загрузки, закрывает вкладки, открывает сайты и программы, помнит то, что ты ему рассказала.

В этом репозитории лежит исходный код **только Хуа Чена**. Вэй Усянь и Лань Чжань — отдельные самостоятельные программы; их готовые `.exe` приложены к релизу, исходников здесь нет.

## Что нового в этой версии

- **Друзья.** Хуа Чен сам находит Вэй Усяня и Лань Чжаня, если они установлены, и разыгрывает с ними совместные сцены. Без них он работает как раньше.
- **Вечер кино.** После 19:00 Хуа Чен зовёт Вэй Усяня: вино «Улыбка императора», кости, выбор топ-3 фильмов (боевики с Джеки Чаном или уся-фэнтези) и три вкладки с поиском в Google.
- **Живые сцены.** Пока ты не пришла, они носятся по панели задач: погони, прыжки через Хуа Чена, дуэли — талисманы и вороны против бабочек и росчерка Э-Мина, флейта, розыгрыши. После кнопки «Иду смотреть» затихают.
- **Реплики.** Фразы в сценах не повторяются за вечер и показываются строго по одной, чтобы облачка не накладывались. Персонажи стоят на расстоянии и смотрят друг на друга.
- **Лань Чжань.** С 8:00 каждые три часа приходит звать Вэй Усяня в Гусу. На 11-й раз догоняет его, уводит за руку, закрывает три вкладки с фильмами, открывает учёбу в Firefox и включает будильник.
- **Несколько моделей ИИ.** Gemini, Groq, xAI Grok, OpenAI или локальная Ollama — выбирается в настройках.
- **Файлы.** Хуа Чен читает документы `.docx`, `.pptx`, `.txt`, `.md`, `.csv`; можно дать путь к папке или путь без расширения. PDF читает только Лань Чжань.

## Установка

1. Скачай `HuaCheng.exe` из раздела **Releases** и положи в постоянную папку. Права администратора не нужны.
2. Запусти. SmartScreen может предупредить о неподписанном файле: «Подробнее» → «Выполнить в любом случае».
3. Правый клик по персонажу → **Настройки…** → выбери модель ИИ и вставь ключ API. Для бесплатного старта подойдёт Gemini.
4. По желанию: меню → **Расширение для Chrome…** — нужно, чтобы он видел и закрывал вкладки.

Чтобы обновиться, закрой Хуа Чена (меню → «Выход») и замени `HuaCheng.exe` новым. Настройки, память и ключи сохранятся — они лежат отдельно, в `%APPDATA%\HuaChengPartner`.

## Управление

| Действие | Как |
|---|---|
| Написать ему | двойной клик или **Ctrl+Alt+Space** |
| Сказать голосом | **Ctrl+Alt+V** (ещё раз — отправить) |
| Показать ему экран | **Ctrl+Alt+S** |
| Отдать текст из буфера | **Ctrl+Alt+C** |
| Спрятать / показать | **Ctrl+Alt+H** |
| Всё остальное | правый клик по персонажу |

## Что он умеет

- **Помощник:** напоминания и будильник, список дел, фокус на 25 минут, утренняя сводка, погода.
- **Компьютер:** открыть сайт, программу или папку, найти файл, разобрать «Загрузки», управлять музыкой.
- **Браузер:** показать и закрыть вкладки Chrome (через расширение), сторожить отвлекающие сайты.
- **Память:** запоминает факты о тебе, ведёт дневник, пишет письма.
- **Сам по себе:** бабочки, Э-Мин (погулять, взмах, мяч), кости, кровавый дождь, красная нить, фонарики, лавка Призрачного города за монеты, праздники.

## Вместе с Вэй Усянем и Лань Чжанем

Скачай `WeiWuxian.exe` и/или `LanZhan.exe` из того же релиза и **запусти каждого хотя бы один раз** — так он записывает себя в общий список, и Хуа Чен его находит. Дальше Хуа Чен будет звать их сам.

- Оба работают и отдельно: Вэй Усянь отвечает за развлечения, Лань Чжань — за работу и учёбу (в том числе презентации PowerPoint).
- Сцену можно запустить вручную: меню → **Гости** → «Позвать Вэй Усяня (вечер кино)» или «Позвать Лань Чжаня». «Отпустить гостей» заканчивает сцену.
- Для совместных сцен версии всех трёх программ должны быть из одного релиза.

Время и поведение настраиваются в `%APPDATA%\HuaChengPartner\config.json`:

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `evening_enabled` | `true` | включён ли вечер кино |
| `evening_hour` | `19` | с какого часа Хуа Чен зовёт Вэй Усяня |
| `film_query` | `"{title} смотреть онлайн"` | что искать в Google для каждого фильма |
| `lan_enabled` | `true` | приходит ли Лань Чжань |
| `lan_start_hour` | `8` | с какого часа он начинает приходить |
| `lan_interval_h` | `3` | раз в сколько часов |
| `lan_calls_needed` | `10` | сколько раз он зовёт, прежде чем увести |
| `study_urls` | `["https://app.hackviser.com/login"]` | что открыть в Firefox, когда пора учиться |

Менять файл нужно при закрытом Хуа Чене.

## Данные и приватность

- Всё хранится локально в `%APPDATA%\HuaChengPartner`: настройки, память, дневник, список друзей (`friends.json`).
- **Ключи API лежат в `config.json` открытым текстом.** Не выкладывай этот файл и не показывай его на скриншотах.
- Твои сообщения, голос и снимки экрана (только когда ты сама просишь посмотреть) уходят выбранному провайдеру модели. С локальной Ollama ничего не покидает компьютер.

## Сборка из исходников

Нужен Python 3.12 под Windows.

```
pip install -r requirements.txt
pip install pyinstaller
python main.py          :: запуск без сборки
build.bat               :: соберёт dist\HuaCheng.exe
```

## Устройство кода

| Файл | Что внутри |
|---|---|
| `main.py`, `hua.py` | окно персонажа, меню, настройки, анимация |
| `characters.py` | характер, позы и реплики |
| `agent.py` | ИИ: провайдеры и инструменты |
| `evening.py` | совместные сцены, очередь реплик, списки фильмов |
| `ipc.py` | поиск друзей и связь с ними |
| `eming.py`, `effects.py` | Э-Мин, бабочки, облачка реплик и прочие эффекты |
| `life.py`, `features.py`, `tools_pc.py` | таймеры, память, погода, работа с файлами и программами |
| `chat.py`, `bridge.py`, `config.py`, `phrases.py` | чат, связь с Chrome, настройки, фразы |
| `assets/` | спрайты, `poses.json`, расширение для Chrome |

Если будешь менять код, не трогай формат сообщений в `ipc.py` и названия поз — иначе Вэй Усянь и Лань Чжань из релиза перестанут понимать Хуа Чена.

## Известные ограничения

- Только Windows 10/11.
- Вкладками управляет только в Chrome и только с установленным расширением.
- Голосовой ввод работает с Gemini, OpenAI и Groq; с Ollama вместо него открывается диктовка Windows (Win+H).
- В полноэкранных приложениях персонаж прячется.
